# PyStock CLI - Sistema de Gestión de Inventario

Aplicación de línea de comandos (CLI) desarrollada en Python para administrar el catálogo de productos, controlar existencias en tiempo real y gestionar ventas de forma segura.

## Funcionalidades

- **Registro de catálogo:** Alta de productos asociados a un código único (SKU).
- **Control de ventas:** Descuento automático de stock con bloqueo preventivo ante falta de existencias.
- **Alertas de reposición:** Aviso automático cuando un artículo cae a 3 unidades o menos.
- **Gestión de tarifas:** Aplicación de descuentos porcentuales con validación de rangos.
- **Validación de entrada:** Protección contra datos inválidos o errores de formato en consola.
